  2. USB telemetry radio (Linux): /dev/ttyUSB0,57600
  3. USB telemetry radio (Windows): com3,57600

Set this in the relay server start command: python3 relay/ranch_server.py --connection <string>

Relay Server

The relay server must be running before Upload or Cockpit will work. Weather and airspace overlays also go through it.

Start the relay server (run once per session)
  1. Open a terminal in the ranchdrone-kit folder.
  2. Run: python3 relay/ranch_server.py --connection udp:127.0.0.1:14550
  3. Open this page at http://localhost:8765/ — not by double-clicking the file.
  4. The green "relay ok" badge in the top bar confirms it is running.
